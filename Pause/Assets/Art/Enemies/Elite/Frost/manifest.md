# Frost Elite Ships

## Rimebreaker

`rimebreaker.png` is an art-only 1344 x 192 flight strip for Claude's elite
behaviour test. It has seven 192 x 192 cells, all inset by at least 16 pixels.

| Cell | State |
| --- | --- |
| 0 | Landed / engines off |
| 1 | Grounded idle, restrained coolant glow |
| 2 | Lift-off ignition |
| 3 | Airborne straight hover |
| 4 | Bank left |
| 5 | Bank right |
| 6 | Second-heart damage — full flight-capable hull with cracked ice plating and a damaged thruster |

The craft is top-down, compact, and industrial: rime steel, chipped ice
plating, copper clamp braces, cyan coolant conduits, magenta warning lamps,
and paired rear thrusters. It is not runtime-wired; gameplay can consume the
strip without changing player-ship assets.
