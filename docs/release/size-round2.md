**The AAB is not under 100 MB and cannot be with these levers.** What remains (152 MB): backdrops about 55 MB compressed (exempt), the other ASTC textures about 45 MB (hulls, bosses, planetfall, weapons: already ASTC, deflate gains little), libunity 8.6 MB + libil2cpp 6.6 MB, music about 12 MB (user's call), serialized data. `bundletool` is not installed on this machine, so no `get-size total`; an Unity AAB has no per-density or per-language splits, only the ABI split (ARM64 only already), so the download is within about 1 MB of the AAB size, i.e. roughly 150 MB. Getting under 100 MB needs Play Asset Delivery (fast-follow or on-demand packs for Tide/Storm/Desert backdrops and planetfall sheets) or a 6x6/8x8 change on non-backdrop art or the music at lower quality. See "What is left" below.

Per-step AAB builds were not run (each costs a heavy queue slot); the per-step numbers are file-level deltas, which are exact for the skins (incompressible PNG TextAssets) and an estimate for the audio.

## Step 1: ship skin sheets (commit "Ship skin sheets..." and "Skin sheets: quantizer now keeps alpha exact...")
- 60 PNG `.bytes` under `Art/Resources/ShipArt/Skins`: **21.04 MB -> 4.78 MB** (-16.3 MB, same in the AAB). Dimensions (2304x768), file names, `.meta` and the `TextAsset` / `LoadImage` path are unchanged; the new files are palette PNGs with tRNS, which `LoadImage` reads.
- Quantizer: `scripts/tools/quantize_skins.py`. Count-weighted median cut + 8 weighted k-means passes over the unique RGBA colours (3-4.5k per sheet), no dithering. A first version (alpha as one more axis) broke `ShipSkinsTest` ("stock silhouette pixel for pixel"): the shield, collider and nozzle bakes need the alpha channel identical to the stock hull. The final quantizer keeps **alpha exact** (every palette entry has one alpha, pixels only map to entries with their own alpha) and gives lone outlier pixels their own palette entry (a rare semi-transparent red glint was turning dark).
- Quality, all 60 sheets (`size-round2-skin-metrics.tsv`): PSNR 49.8 to 56+ dB (alpha-premultiplied), max per-channel error 42 (was 173 before the outlier fix). No sheet showed banding or lost 1 px outlines, so none was left unquantized.
- Previews (`docs/release/size-round2-previews/`, `_zoom.png` dark and `_zoom_bright.png` bright: original | quantized | diff x6, 3x zoom of the busiest 256 px crop): UFO Abductor / Bone, Ninja Ronin / Night, Crimson Halo Seraph / Night, Lightning Hazard, Jade Phantom Wraith, Gold Warden Regent, Neon Comet Kaneda, Saboteur Jester, Paranoid Signal, Solar Fang Neon (13 sheets). Generated by `scripts/tools/skin_preview.py`.

## Step 3: build settings (commit "Build settings ...")
- IL2CPP code generation: Faster (smaller) builds (`il2cppCodeGeneration Android: 1`); managed stripping Medium (`Android: 2`). The build log now prints `[BUILD] stripping=Medium il2cppCodeGen=OptimizeSize minifyRelease=None` to confirm.
- `Assets/link.xml`: `Assembly-CSharp` and `Google.Play.Games` preserved whole (JsonUtility types `ProgressSnapshot`, `AccountBackups`, leaderboard and ambient defs, reflection-built tables, the GPGS JNI callbacks). `UnusedAssetGuardTest` exempts `Assets/link.xml`. Check of the built `global-metadata.dat`: `ProgressSnapshot`, `AccountBackups`, `LeaderboardService`, `GooglePlayGames` all present. Not runtime-tested on a device (no installs allowed).
- Packages removed: `xr.legacyinputhelpers`, `timeline`, `2d.tilemap`, `multiplayer.center`, `ai.navigation`, `collab-proxy`; built-in modules `accessibility, adaptiveperformance, ai, assetbundle, cloth, director, terrain, terrainphysics, tilemap, umbra, unityanalytics, unitywebrequestassetbundle, vectorgraphics, vehicles, video, vr, wind, xr`. Kept on purpose: `screencapture` and `uielements` (the Unity MCP package compiles against them), `unitywebrequest*` (GPGS), `physics`, `particlesystem`. The project compiled and the editor tests ran with them gone; scenes only carry the always-present `NavMeshSettings` block. `packages-lock.json` updated.
- Unity MCP: not gated. Its runtime asmdef lives in the git package cache (cannot be edited, no per-platform switch), and with Medium stripping nothing of it survives: the built metadata has 0 hits for `MCPForUnity` and `Newtonsoft`. So nothing is left to gate.
- `play-services-nearby`: removed from `GooglePlayGamesPluginDependencies.xml` and `mainTemplate.gradle`. The plugin only touches Nearby through lazy `AndroidJavaClass("com.google.android.gms.nearby...")` calls inside `PlayGamesPlatform.Nearby`/`InitializeNearby`, which the game never calls (nothing outside the plugin mentions Nearby), and sign-in, achievements and leaderboards use `play-services-games-v2`. Risk: the plugin xml is third-party code, so a plugin update will bring the dependency back; sign-in is not device-verified. Revert that one hunk if in doubt (about 0.3 MB of dex).
- R8 minify: skipped. The plugin's `Proguard/games.txt` is only honoured through a custom proguard file, `useCustomProguardFile` is 0, and without a device to prove sign-in survives shrinking the 0.5-1 MB is not worth the risk. `classes.dex` is only 0.8 MB deflated now anyway.
- Space `Backdrop/anim.png` + `anim.json`: skipped. `WorldBackdropTest` (lines 439, 1265, 1720), `BackdropCellClipTest` and `SpacePlanetSheetTest` load `anim` by name for every world, and it is a backdrop folder file. About 0.5 MB.

## Step 2: death / gate / shockwave SFX (last commit, droppable)
- `EnemyDeathAudioImporter` (version 4) now writes an Android-only sample-settings override: clips <= 0.5 s ADPCM, longer clips Vorbis quality 0.6, both still `DecompressOnLoad` + preloaded (no first-kill decode stall). The Default tab stays PCM (editor, desktop and iOS unchanged), so the existing import checks still hold; `EnemyDeathAudioTest` gained a check for the Android override.
- 264 clips: 18.01 MB PCM -> about 2.8 MB (Vorbis 214 clips: 16.1 -> 2.25 MB; ADPCM 50 clips: 1.9 -> 0.54 MB), estimated with libvorbis / IMA ADPCM through libsndfile (`scripts/tools/sfx_audition.py`). Measured in the build report: Sounds 30.6 -> 15.3 MB uncompressed (music unchanged). AAB effect about -12 to -13 MB (PCM deflates only to 15.4 MB).
- Audition set: `docs/release/size-round2-audition/` has before (`__before_pcm.wav`) and after (`__after_vorbis.wav` / `__after_adpcm.wav`, encoded then decoded) for boss_ember, boss_tide, boss_frost_scream, boss_verdant_scream, ember_alien_scream, space_elite_orbit_reaver_scream, ember_fighter_1, frost_mine, space_rock_crater, gate_smash, gate_crack, shield_release. **Please listen before keeping this commit.** The audition files come from libvorbis, Unity's encoder differs slightly in bitrate, so judge it as "about right", and listen again on a build.
- To drop it: `git revert` or drop the last commit of the branch; nothing else depends on it.
