# Rail and world visual target

The user's approved reference is [rail-world-target.jpeg](rail-world-target.jpeg).
This is the visual target for ongoing world and rail work.

- Thick industrial rails stay visible on both screen edges, roughly 13–15%
  of the reference width per side; avoid cropping them down to lamp slivers.
- Rugged gunmetal plates, copper brackets, ribbed hoses, dense pixel detail.
- Saturated neon with bright cores: Space pink/cyan, Forest green/mint,
  Frost cyan/ice blue, Ember orange/amber.
- Backdrop reaches the rail contours with no opaque exterior black bars.
- Preserve the art's proportions; extend coverage through scrolling repeats.
- Assess the composed phone view against this reference before calling it
  visually complete. Passing binding or import checks alone is insufficient.

`CameraFit.GameplayHalfWidth` frames the full rails in gameplay/tutorial;
other scenes retain their existing framing. This exposes more world area and
increases the visible vertical distance, including obstacle approach distance.
`WorldRailReview.Run` captures at the reference's 900 × 1600 aspect ratio.
